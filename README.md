# 우리동네 이야기

전국 226개 시·군·구를 같은 잣대로 비교하는 공공데이터 대시보드.
민선 9기 광역단체장 16명의 공약 87건, 2026년 예산, 시군구 세금 성적표, 전국 67개 업종의 개·폐업까지.

## 산식은 전부 공개합니다

- **세금 성적표 등급**: 같은 유형(광역/시/군/구)끼리 3지표 백분위 평균 — 재정자립도(2025) / 체납 잔액 비율(2024, 낮을수록 좋음) / 지방세 5년 연평균 성장(2019→2024). 75+ A, 50+ B, 25+ C, 미만 D.
- **체납 비율**: 체납 잔액 ÷ (징수액 + 체납 잔액), 2024 결산.
- **업종 증감률**: 2025년 (개업 − 폐업) ÷ 영업 중.
- **생존곡선**: 2019~20년 개업 음식점·카페 5년 추적, 표본 300곳 이상만.
- 결산(확정)과 예산(계획)을 섞지 않습니다. 모든 수치는 원자료에서 직접 계산했습니다.

## 기술

외부 라이브러리 0개. 순수 정적 사이트 (HTML + ES5 JS + JSON). 지도는 자체 투영 SVG.

```
index.html   CSS 전체
app.js       렌더링 로직
data.js      시군구 226 + 광역 16 + 공약 87
map.js       SVG 지도
commerce-nation.json  67개 업종 상권 통계
brands.json / brands-region.json
addr2/       주소 연대기 231개 청크
```

로컬 실행: `python3 -m http.server 8791` (fetch 기반이라 file:// 불가)
