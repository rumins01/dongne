# 우리동네 이야기

공약은 잘 지켜지고 있을까, 세금은 어디로 가고, 가게는 왜 생기고 왜 사라질까.
전국 226개 시·군·구를 같은 잣대로 비교해 보여주는 공공데이터 대시보드입니다.

「정치인 도감」(제22대 국회) 후속편이에요.

## 무엇을 볼 수 있나요

- **세금 성적표** — 재정자립도 · 체납 · 세수 성장 세 가지를 같은 유형(광역/시/군/구)끼리 비교해 A~D 등급
- **우리지역 공약과 경제생활** — 민선 9기 광역단체장 16명의 공약 87건과 지역 살림·상권
- **가게 흥망사** — 전국 67개 업종의 개업·폐업, 한 주소에 어떤 가게가 거쳐 갔는지 보여주는 주소 연대기
- **브랜드 지도** — 같은 상호로 신고된 인허가를 모아 추정한 브랜드 규모와 지역 분포

## 만드는 원칙

- 모든 수치는 원자료에서 직접 계산했고, 산식과 한계를 화면 각주로 공개합니다
- 결산(확정)과 예산(계획)을 섞지 않습니다
- 등급은 절대평가가 아니라 **같은 유형 안에서의 상대 위치**입니다. 광역·시·군·구는 재정 구조가 달라 섞어서 줄 세우지 않습니다
- 인허가 데이터는 신고 기준이라 실제 영업 상태와 차이가 있을 수 있습니다

## 기술

외부 라이브러리 없이 순수 HTML · CSS · JavaScript로 만들었습니다. 지도도 SVG 자체 투영입니다.
첫 진입 시 약 5.5MB의 데이터를 진행률과 함께 미리 받고, 이후에는 화면을 넘겨도 다시 기다리지 않습니다.
